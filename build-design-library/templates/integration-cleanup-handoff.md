# Integration, Cleanup, and Handoff Checklist

## Integration

- [ ] Inspect every family report, artifact, commit, and changed file.
- [ ] Inspect branch ancestry before integration.
- [ ] Check one owner per component, symbol, shared file, process, and worktree.
- [ ] Check every upstream acceptance receipt.
- [ ] Reconcile conflicts by intent against the accepted contract.
- [ ] Run duplicate-symbol checks.
- [ ] Resolve source and license records.
- [ ] Resolve generated files under project policy.
- [ ] Run package exports and style generation.
- [ ] Load public assets from application routes.
- [ ] Exercise authentication and authorization paths.
- [ ] Exercise real API paths or stop at labelled proposed seams.
- [ ] Inspect the owner of each public hostname, port, and route-registry entry before binding it.
- [ ] Use a unique session or preview port, or attach read-only, when another session owns the route.
- [ ] Run the supported development lifecycle.
- [ ] Prove startup through that lifecycle, not a temporary preview or standalone workaround.

## Review and verification

- [ ] Run family targeted checks.
- [ ] Run type and lint checks.
- [ ] Run the design-qa scanner and record its limited scope.
- [ ] Run design-qa judgment and live gates.
- [ ] Run complexity review.
- [ ] Run test hardening.
- [ ] Run browser readback for every required cell.
- [ ] Reject blank, failed, stale, wrong-state, and wrong-mode captures.
- [ ] Run real application journeys.
- [ ] Run the full project verification command on unchanged code.
- [ ] Get independent product acceptance.
- [ ] Reconcile every approved matrix row with evidence.

## Cleanup

- [ ] Inspect uncommitted state in every task-owned worktree.
- [ ] Record every task-owned exact process identifier, public hostname or port, and route-registry entry.
- [ ] Record every unpushed commit.
- [ ] Stop only exact processes started by this run.
- [ ] Keep uncertain worktrees and report them.
- [ ] Remove only exact authorized temporary assets.
- [ ] Inspect generated files before removal.
- [ ] Read external work items before any status update.
- [ ] Update only exact authorized work items.
- [ ] Read updated work items back.
